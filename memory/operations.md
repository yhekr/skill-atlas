# Среда и практические замечания

Наблюдения на 2026-09-30; перед повторением проверять текущую среду. Полная процедура — в [README](../README.md), доказательства и ограничения — в [TESTING](../TESTING.md).

## GitHub и локальные проверки

- `origin` настроен как `git@github.com:yhekr/skill-atlas.git`. В этой среде SSH-авторизация не работала, HTTPS через Git Credential Manager работал. [Run-CI.ps1](../scripts/Run-CI.ps1) временно использует HTTPS, не меняя origin.
- [Ci.Common.ps1](../scripts/Ci.Common.ps1) получает API-авторизацию через `GH_TOKEN`/`GITHUB_TOKEN` либо Credential Manager. Не выводить результат `git credential fill`, токены или заголовки запросов.
- В CI Spectre.Console может добавлять ANSI из-за `GITHUB_ACTIONS=true` даже с `AnsiSupport.No`. Тест renderer уже исправлен отключением автоматических enrichers. При похожей регрессии воспроизводить окружение CI, сохраняя проверку управляющих символов из данных.

Кадры/видео находятся в ignored `artifacts/demo`, доступ ревьюеров обеспечивается вложением PR. `node --test tests/web` работает на Windows без зависимости от shell-раскрытия `*.test.mjs`.

## Docker Sandboxes и Central

- Рабочий Docker Engine не означает рабочий Docker Sandboxes: отдельные `sbx` и `sandboxd` устанавливаются независимо. На Windows официальный пакет — `Docker.sbx` через winget, каталог исполняемых файлов — `%LOCALAPPDATA%\DockerSandboxes\bin`.
- После установки PATH уже открытого процесса оставался старым. Помогает новый терминал либо обновление PATH процесса из Machine/User. Для скрипта также нужны Git Bash и jq; наличие jq в локальных ignored artifacts не гарантируется в другом клоне.
- [sbx-codex.sh](../sbx-codex.sh) создаёт или переиспользует соседний worktree и ветку. Имя: 2–63 строчные латинские буквы/цифры/дефисы, первый символ — буква/цифра, `default` зарезервировано. Чужие папки, занятые ветки и изменения не перезаписываются.
- Правильный вызов передаёт **две** рабочие папки: `WORKTREE` и `GIT_COMMON_DIR`, обе на запись. Старое предположение о специальном аргументе `:git` неверно.
- Рабочие папки передаются в `sbx create`; `sbx run` существующего sandbox отвергает повторную передачу путей. Скрипт сверяет агент и обе папки через `ls --json`, затем подключается по имени с обновлёнными переменными Central.
- `GIT_DIR` и `GIT_WORK_TREE` внутри sandbox обходят Windows-путь в файле `.git` worktree. Хостовый файл `.git` не переписывается; Git-метаданные общие с хостом. При переходе к другому репозиторию эти переменные нужно сбросить.
- Central proxy по умолчанию использует порт **19516**, хост для sandbox — `host.docker.internal`. Ключ получается в памяти через Central; не сохранять его или URL с ним в документации/логах. `/models` возвращал 404 и не подходит как проверка готовности этого proxy.
- `balanced` блокирует локальный порт Central по умолчанию. Скрипт добавляет узкое разрешение на один TCP-порт для одного sandbox, не изменяя явные запреты. В sbx `host.docker.internal` нормализуется в `localhost` при проверке политики.
- На Windows SpaceSniffer может кратковременно удерживать подпапки и мешать переименованию снимков containerd. Procmon показал эту гонку; после закрытия сканера 500 переименований и настоящая подготовка образа прошли. Администраторские права её не устраняли. Отдельно распаковка образа требует свободного места сверх размера скачивания. Источник: [TESTING](../TESTING.md), проверка 2026-09-30.
- Короткий существующий TEMP/TMP помог обойти ограничение пути сокетов sandboxd. Настраивать до старта службы; не удалять сокеты работающего процесса и не сбрасывать Sandboxes при обычном повторении запуска.
- Для проверки вывода `sbx run` нужен TTY: неинтерактивное подключение может вернуть 0 без вывода Codex. Стандартное предупреждение sbx об отсутствии OpenAI credentials не мешает отдельному провайдеру Central; не добавлять другой ключ только ради этого предупреждения.
- Успешный Docker-контейнер, сеть, авторизация Central и реальная сессия Codex — отдельные проверки. Реальные Codex/Central и Git внутри sbx подтверждены 2026-09-30, подробности в [status.md](status.md) и [TESTING](../TESTING.md).
