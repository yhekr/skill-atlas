- Настоящий Docker smoke test подтвердил `git status` и коммит во временном worktree с общими Git-метаданными и переменными окружения; исходная ветка осталась неизменной.
- **2026-09-30 полный запуск подтверждён**: исправленный [sbx-codex.sh](../sbx-codex.sh) создал настоящий sandbox из `codex-docker`, вывел `codex-cli 0.149.1` в TTY и при повторном подключении получил `CENTRAL_OK` через Central (`gpt-5.6-sol`, модель по умолчанию). Новый sandbox во временном Git-репозитории автоматически получил разрешение на порт Central и ответил `CENTRAL_FRESH_OK`. Внутри него созданы файл и Git-коммит; коммит виден на хосте, исходная ветка не изменилась. Временный sandbox удалён.
- Исправлены повторное подключение (рабочие папки допустимы только при создании) и правило сети для порта Central в пределах sandbox. Скрипт проверяет совпадение агента/папок и уважает явные сетевые запреты. Тесты: 36 общих сценариев launcher, ещё один Windows-сценарий; дополнительный Docker smoke остаётся отдельным. Источник: [TESTING](../TESTING.md).
