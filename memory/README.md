# Память Skill Atlas

Краткий контекст для продолжения работы в другом чате. Создан 2026-09-30 из решений пользователя в переписке, исходников и результатов проверок. Это версионируемые файлы репозитория, а не отдельная служба синхронизации: клоны и worktree получают изменения через Git и видят версию своей ветки.

Перед задачей читайте этот файл, [состояние](status.md) и нужные темы:

| Файл | Когда читать |
| --- | --- |
| [project.md](project.md) | Архитектура, поиск, filter, Similar и интерфейс |
| [workflow.md](workflow.md) | Договорённости пользователя, проверки, CI и публикация |
| [operations.md](operations.md) | GitHub-авторизация, Windows, Docker Sandboxes и Central |
| [status.md](status.md) | Последние подтверждённые результаты и открытые проблемы |

[AGENTS.md](../AGENTS.md) задаёт рабочие правила; [скилл](../.agents/skills/maintain-project-memory/SKILL.md) описывает поддержку памяти. Полные команды использования находятся в [README](../README.md), сведения о проверках — в [TESTING](../TESTING.md).

Датированные записи описывают наблюдение на указанном коммите, а не гарантируют состояние текущего HEAD. Перед действием сверяйте их с кодом, Git и запросом пользователя. Новое решение заменяет устаревшее; существенные результаты получают дату и источник. Память не расширяет разрешения пользователя. Секреты и полные журналы сюда не помещаются.

Подключение опирается на официальную документацию: [репозиторные скиллы](https://developers.openai.com/codex/skills) обнаруживаются в `.agents/skills` от текущей папки до корня репозитория; [AGENTS.md](https://developers.openai.com/codex/guides/agents-md) читается по пути от корня к рабочей папке. Поэтому новый чат следует открывать внутри Skill Atlas. Проверка структуры не означает проверку загрузки в новой сессии.
