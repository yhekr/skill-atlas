# Проверка Skill Atlas 1.0.1

## Запуск Codex в sandbox

`scripts/test-sbx-codex.sh` проверяет `sbx-codex.sh` с настоящими Git worktree и jq; Central и sbx подменяются тестовыми исполняемыми файлами. 22 сценария включают создание и повторное использование worktree, сохранение незакоммиченных файлов, существующие/занятые ветки, чужие репозитории, detached HEAD, отсутствие sbx, пробелы и shell-символы в аргументах, неверные имена, порты, JSON и ключи, CRLF, ошибки Central и коды выхода sbx. Тесты запускаются локально через Git Bash и в Linux-задаче GitHub Actions; реальных модельных запросов в них нет.

Отдельная проверка установленного Central 1.11.0: `proxy start --return-key` возвращает ключ; обработчик `/wire/<proxy-key>/codex/openai/v1/responses` на порту 19516 возвращает ожидаемый HTTP 400 `model must be set` на пустой запрос. GET `/models` возвращает 404, поэтому он не используется как проверка готовности. Запрос на генерацию не отправлялся, ключ не печатался.

Полный запуск контейнера не проверен: sbx в текущем окружении отсутствует. Тесты проверяют сформированную команду с передачей параметров Codex после `--`, но не реализацию этого интерфейса конкретной сборкой sbx.

## Скрипт запуска и наблюдения за CI

`scripts/Test-CI.ps1` содержит 23 проверки без сети, токенов и реальных задержек. Проверяются HTTPS/SSH-адреса и отказ от посторонних URL, выбор точного SHA/ветки/события, интервал 120 секунд, переходы queued → in_progress → success, неуспешные заключения (в том числе cancelled), задержка появления запуска, однократный workflow_dispatch, изменение удалённой ветки, таймаут и ошибки API. Эти проверки включены в GitHub Actions для Windows и Linux.

Ручной запуск `scripts/Run-CI.ps1` проверен на существующем коммите: push без изменений, обнаружение нужного запуска и завершение с `success`.

Горизонтального переполнения страницы нет. После добавления веб-интерфейса локально прошли **110 тестов**: 88 тестов Core/CLI и 22 теста веб-API/Markdown. Веб-тесты проверяют страницу с полем репозитория, цикл scan/read, ссылки на commit, некорректные адреса и ветки, истёкшие результаты, отмену, занятость сканера и очистку HTML от исполняемых элементов.

[Актуальный CI в GitHub Actions](https://github.com/yhekr/skill-atlas/actions/workflows/ci.yml) проверяет Windows и Linux и прикладывает TRX-отчёты и собранные приложения к каждому запуску.
